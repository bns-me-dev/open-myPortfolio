# BNS.me — Portfólio Pessoal

Portfólio pessoal desenvolvido para apresentar projetos, soluções web e sistemas criados por mim.

O objetivo do projeto é centralizar:

- projetos reais desenvolvidos para clientes;
- projetos open-source disponíveis para download;
- soluções digitais prontas para uso;
- informações de contato profissional.

---

## Tecnologias Utilizadas

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### Integrações
- EmailJS
- WhatsApp API (via wa.me)

### Dados
- JSON local para gerenciamento dinâmico dos projetos

---

## Funcionalidades

- Layout totalmente responsivo
- Navegação mobile com menu lateral
- Portfólio renderizado dinamicamente via JSON
- Filtro por categoria de projetos
- Modal com detalhes dos projetos
- Formulário de contato com validação
- Integração com WhatsApp
- Estrutura preparada para venda de soluções digitais
- Estrutura preparada para integração futura com checkout online
